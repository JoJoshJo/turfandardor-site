# turfandardor-site

Marketing website for [Turf & Ardor](https://turfandardor.com) — the dating and meetup app for football fans.

## Pages
- `index.html` — Homepage
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Service
- `support.html` — Support / FAQ

## Hosting
This repo is served via GitHub Pages with custom domain `turfandardor.com`.

## Update workflow
1. Edit the relevant HTML file
2. Commit and push to `main`
3. GitHub Pages auto-rebuilds within ~1 min
4. Changes live at https://turfandardor.com
